# Ajustes visuais dos minigames

- Tema escuro nas duas páginas (Realidade ou Cyberpunk? e Jogo da Senha).
- Quiz com enunciado centralizado e respostas maiores, como texto clicável sem grandes caixas.
- Verde/turquesa para Realidade; rosa para Cyberpunk.
- Jogo da Senha com regras em linhas simples; verde se cumpridas, vermelho se pendentes.
- Imagens de fundo locais para funcionar sem internet.
